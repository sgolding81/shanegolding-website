About Shane Golding

I like turning specific problems into dependable, understandable software.

I build focused tools, websites, and experiments. Recent work spans browser interfaces, native Linux services, developer tooling, and small game prototypes.

I’m drawn to straightforward technology, clear interfaces, and the small implementation details that make something pleasant to use and easy to maintain.

About this site

This site is deliberately lightweight. It uses hand-written HTML, CSS, and JavaScript, system fonts, and no analytics or advertising trackers. The interactive Snake experiment is built with the Canvas API and keeps its high score on your device.

The source is structured as ordinary static files so the pages remain fast, resilient, and understandable without a framework or build step.
